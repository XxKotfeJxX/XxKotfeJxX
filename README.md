# Hi, I'm Andrii Andrusevych

I build practical software with **Go, TypeScript, and Python**. My projects
range from self-hosted web platforms and infrastructure tools to desktop
applications with custom editing workflows.

I enjoy taking a project beyond the prototype stage: defining the
architecture, building the product interface, integrating external services,
writing tests, packaging it with Docker, and setting up a maintainable GitHub
workflow.
